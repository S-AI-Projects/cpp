## Runner Path Resolution

Exercism test runners and CI workflows resolve files as follows:
1. **Config-Driven Resolution**:
   - The test runner reads `exercises/practice/raindrops/.meta/config.json`.
   - The runner resolves paths listed in `files.test` (`raindrops_test.cpp`) and `files.solution` (`raindrops.cpp`, `raindrops.h`) relative to the exercise directory root.
   - For track validation, `files.example` (`.meta/example.cpp`, `.meta/example.h`) is substituted in place of the solution files before executing the test build.
2. **CMake-Driven Resolution**:
   - When building locally or via Docker, `CMakeLists.txt` inspects the directory name (`raindrops`), replaces `-` with `_` to obtain `raindrops`, and configures the test executable using `${file}_test.cpp` (`raindrops_test.cpp`) and `${file}.cpp` (`raindrops.cpp`).
