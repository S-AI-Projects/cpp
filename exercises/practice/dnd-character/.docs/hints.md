# Hints

## General

- An ability score is generated by rolling four 6-sided dice (`1..6`) and summing the highest three (`3..18`).
- `Character` computes its six ability scores once at construction and sets `hitpoints = 10 + modifier(constitution)`.

## Debugging Negative Ability Modifiers

The specification defines the constitution modifier as:

- Subtract `10` from the ability score, divide by `2`, and **round down** ($\lfloor (\text{score} - 10) / 2 \rfloor$).

### Common Pitfall: C++ Integer Division Truncates Toward Zero

In C++, dividing two signed integers with `/` **truncates toward zero** rather than rounding down toward $-\infty$:

- For scores $\ge 10$ or even scores below $10$ (such as `score = 4`), truncation and floor rounding produce the same result (`(4 - 10) / 2 == -3`).
- For **odd scores below `10`** (`3`, `5`, `7`, `9`), `(score - 10)` is negative and odd, so integer division rounds toward `0` instead of down and produces a value that is `1` too high.

### Diagnostic Input

Test your `modifier` function on the smallest valid ability score, `score = 3`:

- Expected (`floor((3 - 10) / 2.0)` = `floor(-3.5)`): `-4`
- Erroneous integer division (`(3 - 10) / 2`): `-3`

Similarly, `score = 5` must return `-3` (not `-2`), `score = 7` must return `-2` (not `-1`), and `score = 9` must return `-1` (not `0`). Use floating-point division paired with `std::floor` (from `<cmath>`) or an explicit floor-division adjustment for negative odd dividends.
